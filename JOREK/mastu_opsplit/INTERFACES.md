# Implementation ownership and interface freeze — 2026-11-02

This study lives in this repository under `JOREK/mastu_opsplit`; bulk output stays outside Git. No production run or training may pass an unverified scientific gate. Synthetic tests are explicitly labelled and cannot pass Gates A/B.

Python package: `src/mastu_opsplit`. Commands accept `--config PATH`, `--output PATH`, and `--dry-run` where execution is applicable. YAML configuration, JSON reports, HDF5 trajectory files. Outputs must reject accidental overwrite. Errors return nonzero. Tests use pytest. No dependency checkout is modified.

Coordinator owns common.py, __init__.py, evaluation.py, sampling.py, configs/{sampling,evaluation,resources,train}.yaml, scripts/{evaluate,preflight}.py, README.md, pyproject.toml, project progress and beads. Simulation agent owns case.py, runner.py, scripts/{prepare_case,run_case}.py, slurm/simulate.sbatch, configs/case.yaml, reports/case_contract.md and simulation audit evidence, tests/test_case.py and test_runner.py. Numerical agent owns numerical.py, data.py, scripts/export_dataset.py, reports/{data_contract,equations,numerical_status}.md, tests/test_numerical.py and test_data.py. Learning agent owns learning.py, training.py, scripts/train.py, configs/lsplinefno.yaml, slurm/train.sbatch, reports/learning_status.md, tests/test_learning.py and test_training.py. Agents do not edit beads or others' files.

Common coordinator utilities: `load_config(path) -> dict`, `write_json(path, value)` (exclusive creation), `sha256_file(path) -> str`, `config_hash(mapping) -> str`, `require_gates(path, required: tuple[str,...])` where JSON is `{"A":{"status":"passed","evidence":[...]}, ...}`. Gate evidence paths must exist. Imports may be used once common.py appears; otherwise use local standard library functionality.

Frozen storage contract: native state coefficients remain separate from samples `[time,N_source,C_state]`; physical coordinates `[N,2]` in meters, shared fixed affine bounds `[2,2]` with axis rows `[min,max]`; source/query IDs, patch/boundary labels, quadrature/basis/connectivity persist separately. Axisymmetric quadrature physical volume is `2*pi*R*dR*dZ`. Learned labels are named pointwise strong terms or fluxes with declared test-basis assembly; never residual coefficients disguised as samples. Selected residuals plus remainder reconstruct total. Geometry hash shared across trajectory manifests. All source equations and temporal/constraint mapping remain provisional until verified against pinned source.

Array implementation may use NumPy for data/numerics and PyTorch for learnable paths. Learning boundary accepts `[B,N,C]` fields and `[N,2]` or `[B,N,2]` coordinates with fixed bounds; outputs `[B,N_query,C_out]`. Production API must fail with a concrete missing capability if native JOREK evaluator/export does not exist. No toy PDE can stand in for that backend.
